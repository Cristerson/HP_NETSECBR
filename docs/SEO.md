# Estratégia de SEO - NetSecBR

## Diretrizes Gerais
Todo o conteúdo do website foi estruturado seguindo as melhores práticas de SEO para garantir boa indexação e relevância nos motores de busca.

## Estrutura Técnica
- **URLs Amigáveis:** Uso de URLs curtas e descritivas (ex: `/servicos.html`, `/solucoes.html`).
- **Heading Structure:** Uso semântico e hierárquico das tags H1, H2, H3, garantindo que haja apenas um H1 por página.
- **Meta Tags:** Cada página possui `title` e `description` otimizados para atrair cliques de executivos de tecnologia.
- **Performance:** Uso de HTML/CSS/JS puro para garantir tempo de carregamento rápido (fator crucial para SEO).
- **Responsividade:** Design mobile-first adaptável a todas as telas.

## Palavras-chave Principais
- Consultoria de TI
- Operações críticas de TI
- Transformação digital corporativa
- Cibersegurança para empresas
- Serviços gerenciados de TI
- NOC e SOC 24x7
- Inteligência artificial para negócios
- Migração para Cloud

## Schema.org
A página principal deve incluir marcação estruturada (JSON-LD) do tipo `Organization` ou `LocalBusiness` para ajudar os motores de busca a entenderem o contexto da empresa.
