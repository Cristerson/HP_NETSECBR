# NetSecBR

Este repositório contém a identidade digital e comercial da **NetSecBR**, uma consultoria boutique especializada em tecnologia, operações críticas, inteligência artificial e transformação digital.

## Estrutura do Projeto

```text
netsecbr/
├── website/           # Arquivos HTML do site institucional
├── assets/            # CSS, JavaScript, imagens, ícones e logos
├── presentation/      # Apresentação Institucional em formato PPTX
├── docs/              # Documentação do projeto (Branding, SEO, Conteúdo)
└── README.md          # Este arquivo
```

## Tecnologias Utilizadas

O website foi desenvolvido com foco em performance e SEO, utilizando:
- HTML5
- CSS3 (Puro, responsivo)
- JavaScript Vanilla

## Hospedagem e Publicação

O site foi projetado para ser compatível com hospedagem compartilhada de baixo custo e plataformas modernas como:
- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel

Para publicar, basta fazer o upload ou conectar o repositório à plataforma desejada apontando para a raiz ou para a pasta `website/` (e configurando os caminhos dos assets conforme necessário).

## Posicionamento

A NetSecBR não vende produtos. Entregamos resultados através da integração entre Pessoas, Processos e Tecnologia. Nosso posicionamento é consultivo, executivo e orientado ao negócio.
